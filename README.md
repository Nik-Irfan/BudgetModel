A clean, minimalist, premium budgeting app. Split your salary into pots like **Maybank, AEON, Tabung Haji** and track what's left.

**Live demo:** https://nik-irfan.github.io/BudgetModel/

> Budget first, details on demand. Dashboard shows only budgets. Tap to expand.

### Features (v1.6.1)
- Salary input with RM formatting
- Models: 50/30/20, 80/10/10, Custom builder
- Dropdown dashboard (collapsed by default)
- Expense tracking with over-budget warning
- OG tags fixed for WhatsApp

### Quick Start
```bash
npm install
npm run dev
```
